# W7 ログイン機能 仕様書

## 1. 対象画面
| メソッド | URL | 内容 | ルート名 |
|---|---|---|---|
| GET | /register | ユーザー登録フォーム | register |
| POST | /register | 登録処理 | |
| GET | /login | ログインフォーム | login |
| POST | /login | ログイン処理 | |
| POST | /logout | ログアウト処理 | |

## 2. 入力項目とバリデーション
### 登録
- 名前: 必須
- メールアドレス: 必須、メール形式、users テーブル内で一意
- パスワード: 8文字以上
- パスワード(確認用): パスワードと完全一致
### ログイン
- メールアドレス、パスワード: 認証に失敗したら下記エラー

## 3. エラーメッセージ(一字一句そのまま)
- 名前が空: 名前を入力してください
- メールが空: メールアドレスを入力してください
- メール形式不正: メールアドレスの形式で入力してください
- メール重複: このメールアドレスはすでに登録されています
- パスワード8文字未満: パスワードは8文字以上で入力してください
- 確認用が不一致: パスワードが確認用と一致しません
- ログイン失敗: メールアドレスかパスワードが違います(直前のフォームに戻し、メールアドレスは old() で保持)

## 4. 成功時のリダイレクト先
- 登録成功: 自動ログインして /entries
- ログイン成功: /entries(セッションを再生成する)
- ログアウト: セッションを無効化し /login

## 5. アクセス制御
- 未ログインで /entries, /courses, POST /entries, DELETE /entries/{id} にアクセス → /login にリダイレクト
- /entries の上部に「〇〇さんの時間割」とログアウトボタンを表示
- / と /timetable は、未ログインでも見られるままにする
- /login と /register は、未ログインで開ける

## 6. 受入テストのチェックリスト

### アクセス制御(未ログイン)
- [ ] ログインせずに /entries を開く → /login にリダイレクトされる
- [ ] ログインせずに /courses を開く → /login にリダイレクトされる
- [ ] ログインせずに /entries/create を開く → /login にリダイレクトされる
- [ ] ログインせずに DELETE /entries/{id} を実行 → /login にリダイレクトされる

### 登録(正常系)
- [ ] /register で正しい名前・メール・パスワード(8文字以上)・確認用を入力して登録 → 自動ログインされ /entries に移動し、「〇〇さんの時間割」とログアウトボタンが表示される
- [ ] 登録直後の /entries → 時間割が空(「まだ授業が登録されていません」)

### 登録(異常系)
- [ ] 名前を空にして登録 → 「名前を入力してください」
- [ ] メールを空にして登録 → 「メールアドレスを入力してください」
- [ ] メールを「abc」のような形式不正にして登録 → 「メールアドレスの形式で入力してください」
- [ ] 登録済みのメールで登録 → 「このメールアドレスはすでに登録されています」
- [ ] パスワードを7文字にして登録 → 「パスワードは8文字以上で入力してください」
- [ ] 確認用を違う文字列にして登録 → 「パスワードが確認用と一致しません」
- [ ] 上記いずれの場合も、入力した名前・メールがフォームに残る(old())

### ログイン・ログアウト
- [ ] 正しいメール・パスワードでログイン → /entries に移動する
- [ ] 間違ったパスワードでログイン → /login に戻り「メールアドレスかパスワードが違います」が表示され、メール欄の値が残る
- [ ] 存在しないメールでログイン → 同じメッセージが表示される
- [ ] ログアウトボタンを押す → /login に移動する
- [ ] ログアウト後に /entries を開く → /login にリダイレクトされる
- [ ] ログイン成功時にセッションが再生成される
- [ ] ログアウト時にセッションが無効化される

### 自分専用の時間割
- [ ] /courses から授業を登録 → /entries に反映され、/courses でその授業が「登録済み」になる
- [ ] 自分の時間割に月1がある状態で、別の月1の授業を登録 → 「その曜日・時限にはすでに授業が登録されています」
- [ ] 同じ授業をもう一度登録 → 重複のメッセージが表示される(500エラーにならない)
- [ ] 自分の授業を削除 → /entries から消え、/courses で「登録」ボタンに戻る

### マルチユーザー
- [ ] 2人目を新規登録した直後の /entries → 空で、1人目の授業が混ざっていない
- [ ] 1人目が登録済みの月1「プログラミング入門」を、2人目も登録できる
- [ ] 2人目の /courses → 2人目が登録した授業だけ「登録済み」になる
- [ ] 2人目の月1に授業がある状態で、同じ月1の別の授業を登録 → 重複メッセージで防がれる
- [ ] 1人目で再ログイン → 1人目の授業だけが残っている

### DB確認(psql)
- [ ] users の password 列 → 平文ではなくハッシュ(`$2y$` で始まる)になっている
- [ ] 同じパスワードで登録した2人 → ハッシュ値が異なる
- [ ] ユーザー名・曜日・時限・授業名を JOIN で一覧表示できる
